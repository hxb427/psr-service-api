# PSR Service API

ASP.NET Core 10 Web API for the PSR Service Center management system. Replaces the legacy FastAPI backend with a production-grade .NET implementation.

## Stack

- **.NET 10** (LTS, support until Nov 2028)
- **ASP.NET Core 10** minimal APIs
- **EF Core 10** + **Pomelo.EntityFrameworkCore.MySql**
- **MySQL 8** (RDS in prod, local container or installed instance in dev)
- **JWT auth**, single session per user, BCrypt password hashing
- **Serilog** structured logging to file + console
- **Docker** for deployment to AWS EC2

## Prerequisites

- [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)
- MySQL 8 server (local install, or via Docker: `docker run -d --name mysql -e MYSQL_ROOT_PASSWORD=devpass -p 3306:3306 mysql:8`)
- (optional, for deployment) Docker Desktop, AWS account

After installing the .NET 10 SDK, install the EF Core CLI tool:
```powershell
dotnet tool update --global dotnet-ef --version 10.0.0
```

## Local development

```powershell
# One-time: trust the .NET dev cert (used by Kestrel in Development env)
dotnet dev-certs https --trust

# Restore + build
dotnet restore
dotnet build

# Apply migrations to your local MySQL (creates schema + seeds roles)
dotnet ef database update --project src/PSR.Service.Api

# Run the API (listens on https://localhost:5001 in dev)
dotnet run --project src/PSR.Service.Api

# Run tests
dotnet test
```

On first run, an `admin` user is auto-seeded with password `ChangeMe!2026` (or whatever you set in the `SEED_ADMIN_PASSWORD` env var). The admin must change the password on first login.

### Quick smoke test
```powershell
# Health
curl.exe -k https://localhost:5001/health

# Login (returns JWT + mustChangePassword=true)
curl.exe -k -X POST https://localhost:5001/auth/login `
  -H "Content-Type: application/json" `
  -d '{"username":"admin","password":"ChangeMe!2026"}'
```

## Production deployment

See [docs/aws-setup.md](docs/aws-setup.md) for the full AWS provisioning + first deploy walkthrough. TL;DR: build the Docker image, run via `docker compose up -d` on EC2, with the cert generated by `deploy/scripts/generate-cert.sh`.

## Configuration

Local dev config lives in `src/PSR.Service.Api/appsettings.Development.json`. **Do not put secrets there.** Use environment variables or an `appsettings.Local.json` (gitignored) for secrets like the production DB connection string and JWT signing key.

Required settings:
- `ConnectionStrings:Default` — MySQL connection string
- `Jwt:Signing` — random 32+ char string for signing JWTs (generate one with `openssl rand -base64 48`)
- `Jwt:Issuer` — defaults to `psr-service`
- `Jwt:Audience` — defaults to `psr-service-wpf`
